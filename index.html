TaENDEC API Documentation

External systems (e.g. Open Paging Server, customized ENDEC hardware, or automation scripts) can directly interact with TaENDEC using these HTTP REST endpoints on port 8085.

1. Transmit Live Alert Immediately

Endpoint: POST /api/transmit

{
  "originator": "CIV",            // "EAS", "CIV", "WXR", "PEP"
  "eventCode": "NUW",             // Standard 3-letter SAME Event Code
  "duration": "0515",             // Duration in HHMM
  "fipsCodes": "027109-027045",    // Dash-separated 6-digit SAME county codes
  "additionalText": "Nuclear Power Plant Warning...", // Optional visual/TTS message
  "voice_wav_path": "",           // Optional local /var/lib/... audio path
  "hasAudio": false,              // Set true if voice_wav_path is present
  "skip_translation_in_tts": false
}

2. Schedule Alert for Future Execution

Endpoint: POST /api/schedule

{
  "startTime": "2026-11-19T11:19:00Z", // ISO 8601 Timestamp
  "originator": "CIV",
  "eventCode": "NUW",
  "duration": "0515",
  "fipsCodes": "027109-027045",
  "additionalText": "Scheduled test..."
}

3. Upload Custom Audio Clip

Endpoint: POST /api/upload

{
  "filename": "alert_voice.wav",
  "data": "data:audio/wav;base64,UklGRiQAAABXQVZFZm10IBAAAAABAAEA..." // Base64 encoded WAV/MP3
}

Returns: {"status": "File Uploaded", "path": "/var/lib/eas_alerts/uploads/alert_voice.wav"}
